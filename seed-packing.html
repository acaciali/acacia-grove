Seed Packing List

Adds a starter set of common travel items to the master packing list, grouped into categories (Clothes, Warm Clothes, Summer Clothes, Toiletries, and so on). Items already on the master list are skipped, so this is safe to re-run and won't resurrect items you've deleted — unless you run it again after deleting a starter item, which re-adds it.
